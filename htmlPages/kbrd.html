Learn Alphabet

  • Whatever alphabet you learn, the input language must be English (en)
  • Select the target language
  • Press the key on the physical keyboard corresponding to the highlighted letter on the screen.
  • Do the same with the next highlighted letter and so on.
  • Use the buttons above the screen keyboad to make the task more challenging.
  • Click on letters on the keyboard to create a set of letter you want to learn right now.
  • To LISTEN to the highlighted letter again press ENTER on the physical keyboard
